Publication decisions and proposed contents

No public release is authorized. Andrea authorized uploading the reviewed files to andreaingrao/SHRED-MPC as a private repository, while explicitly keeping the website offline. The full dataset remains local.

Proposed public files are exactly those listed in PUBLIC_FILES.txt at the repository root. This includes maintained source/tests, frozen annotated historical code, required CFD template inputs/mesh, approximately 1.8 MB of curated real evidence, regenerated figures/video, documentation and the static website. The adjacent private-review/ directory is outside that list and must not be published.

Excluded: full dataset, bulk CFD outputs, the 7.2 GB environment, caches, unverified model artifacts, original slides/GIFs, personal machine logs and unrelated scratch files. The original project and its archives remain in place. This export is not a full independent backup; insufficient disk space prevented duplicating 135 GB.
